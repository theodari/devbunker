Bulk operations — NEVER edit files one by one for repetitive tasks. Use CLI tools via `bash`:
- Reformat code: `find . -name '*.cpp' -o -name '*.h' | xargs clang-format -i`

- Rename a symbol: `find . -name '*.cpp' -o -name '*.h' | xargs sed -i 's/oldName/newName/g'`

- List TODOs: `grep -rn 'TODO\|FIXME\|HACK' --include='*.cpp' --include='*.h' .`

- Git bulk: `git diff --stat`, `git log --oneline -20`, `git blame file`
- Install missing tool: suggest `winget install` or `apt install` to user
